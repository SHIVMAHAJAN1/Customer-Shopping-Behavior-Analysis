#Customer Shopping Behavior Data Pipeline and Database Loader.
Project Description
This project provides an end-to-end Python pipeline for loading, cleaning, transforming, and migrating customer shopping behavior data into relational databases. Using Pandas and SQLAlchemy, the workflow handles missing data imputation, column standardization, feature engineering (such as age group classification and purchase frequency mapping), and seamless integration with database systems including PostgreSQL, MySQL, and MS SQL Server.
